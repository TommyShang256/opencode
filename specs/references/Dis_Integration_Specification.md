# DIS 数据处理规范

本文档定义DIS话单数据处理的标准规范，包括数据转换、存储和建模要求。

---

## 1. 数据计算ETL信息

### 1.1 处理目标
- Flink流处理，将Kafka缓存中的数据进行处理后，加载到ClickHouse持久化存储
- Hadoop集群：datacube_dc_dev
- 队列名：datacube_devCompute

### 1.2 数据来源
- 数据来源类型：Kafka
- topic名称：<话单名称>
- 模型名称：<话单名称>
- 别名：Kafka抽取

### 1.3 数据转换

**默认处理逻辑**：默认所有字段转换类型均为「原有字段输出」，即直接从Kafka字段映射输出，不做额外处理。

**TIME字段类型转换**:
- 表达式类型：表达式计算
- 计算公式：通过计算当前时间转为年月日格式（yyyy-MM-dd）得到

**新增字段**：
| 输出字段 | 字段类型 | 字段说明 | 转换类型 | 计算公式 |
| -------- | -------- | -------- | -------- | -------- |
| INSERT_TIME | STRING | 数据入库时间 | 表达式计算 | 通过计算当前时间转为年月日格式（yyyy-MM-dd）得到 |

### 1.4 数据存储
- 目标数据库：ClickHouse
- 数据库表名称：<话单名称>
